Try these before you write any code

  1. Set PSC to 9999 and read the tick: one count is 100 µs. Now set ARR to 4999, 4904 and 9998 in turn — these are the three periods Exercise 3 asks for. Predict each period before you look at the readout.
  2. Halve PSC and watch the counter period halve too, then double ARR to get back where you started. Two different routes to the same period — which one gives you finer adjustment?
  3. Switch to Toggle on update with ARR = 9999 and measure the output period. It is 200 µs, not 100 µs. This is the trap in Exercise 2.
  4. In PWM mode, move CCR while keeping ARR fixed. The frequency never changes, only the duty cycle. Find the CCR that gives a square wave.
  5. Set PSC = 0 and ARR = 99999. Read the warning — then fix it two ways: with a bigger prescaler, or by choosing a 32-bit timer.

In STM32CubeIDE the Prescaler field is PSC and Counter Period is ARR. You type the register value; the hardware adds the +1 in both cases, which is why 9999 gives a division by 10000.
